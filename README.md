# 🌊 Wavey (웨이비)

> 소리의 파도를 따라 즐기는 나만의 미디어 플레이어

로컬에 있는 음악과 영상을 파스텔 물결 위에 띄워 재생하는 미디어 플레이어입니다.
웹으로도 돌아가고, 안드로이드 APK로도 설치할 수 있습니다.

## 브랜드

| 역할 | 색 | 값 |
| --- | --- | --- |
| Primary | 소다 블루 | `#70D6FF` |
| Secondary | 파스텔 민트 | `#A0E7E5` |
| Accent | 코랄 핑크 | `#FF85A1` |
| Background | 크림 아이스 | `#F4F9FC` |

전체적으로 둥근 모서리(`rounded-3xl`), 부드러운 파스텔 그림자, 유리질감(Glassmorphism)으로 맞췄습니다.

## 기능

**음악 모드**
- 재생 중이면 앨범 아트 주변으로 물결이 잔잔하게 번져 나갑니다.
- 앨범 아트는 LP 대신 *물이 차오르는 유리병* — 재생이 진행될수록 물결이 위로 차오릅니다.
- 재생 바의 조작점은 물방울 모양이고, 지나온 구간에는 파도가 흐릅니다.

**비디오 모드**
- `rounded-3xl`로 감싼 뷰어.
- 마우스를 올리면 파스텔 컨트롤 바가 물방울처럼 스르륵 올라오고, 잠시 두면 다시 가라앉습니다.
- 전체 화면 지원.

**재생 목록 — 두 갈래**
- **플레이리스트 탭**: 곡을 하나씩 골라 담는 내 목록. 추가 · 삭제 · 검색.
- **폴더 탭**: 폴더를 지정하면 그 안의 음악과 영상을 통째로 불러옵니다.
  (안드로이드는 폴더 지정을 막아 두어서, 파일 여러 개 고르기로 자동 전환됩니다.)
- 두 목록은 따로 관리되고, 지금 어느 쪽을 재생 중인지 곡 제목 아래에 표시됩니다.
- 재생 중인 곡 옆에는 둠칫거리는 미니 파도 음파.
- 비어 있을 때: *"파도가 조용해요! 미디어 파일을 끌어다 놓아주세요 🌊"*

**감기**
- 재생 바를 손가락이나 마우스로 끌어 원하는 지점으로 옮깁니다.
- 재생 바 아래의 **10초 뒤로 / 10초 앞으로** 버튼으로 정확하게 건너뜁니다.

**벨소리 설정 (안드로이드 앱)**
- 재생 중인 곡 아래 **벨소리로 설정** 버튼 → 전화 벨소리 · 알림음 · 알람음 중 선택.
- **구간만 쓰기**를 켜면 양 끝 물방울을 끌어 원하는 부분만 오려낼 수 있습니다.
  **미리 듣기**로 확인한 뒤 설정하세요. 최대 40초까지, 앞뒤는 자연스럽게 여닫힙니다.
- 곡 사본이 폰의 공용 벨소리 폴더에 들어가고 기본 소리로 지정됩니다.
- 처음 한 번은 *"시스템 설정 변경"* 허용이 필요합니다 (설정 화면이 자동으로 열립니다).
- 곡은 작은 조각으로 나눠 폰에 옮깁니다. 한 번에 보내면 옮기는 동안 화면이 멈춥니다.

**종료 (안드로이드 앱)**
- 뒤로가기를 누르면 *"Wavey를 종료할까요?"* 를 먼저 여쭙고, 확인하면 완전히 종료됩니다.
- 창이 열려 있을 때는 그 창부터 닫습니다.

**자체 업데이트 (안드로이드 앱)**
- 앱을 켤 때, 그리고 다른 곳에 갔다 돌아올 때마다(10분 간격) GitHub 릴리스의
  `version.json` 을 확인합니다.
- 새 버전이 있으면 *"업데이트 하시겠습니까?"* 안내 → 확인하면 APK를 받아 설치 화면까지 이어 줍니다.
- 머리말의 **↓ 버튼**으로 직접 확인할 수도 있습니다. 이때는 결과를 반드시 알려 줍니다
  (최신인지, 못 했다면 왜 못 했는지). 저절로 도는 확인만 조용히 넘어갑니다.
- 처음 한 번은 *"이 출처의 앱 설치"* 허용이 필요합니다 (설정 화면이 자동으로 열립니다).

**껐다 켜도 그대로**
- 넣어 둔 파일이 브라우저 저장소(IndexedDB)에 **파일째로** 보관됩니다.
- 앱을 껐다 켜도 목록, 마지막에 듣던 곡, 볼륨·셔플·반복 설정이 그대로 남습니다.
- 저장 공간이 꽉 차면 알려 주고, 저장에 실패해도 재생은 계속됩니다.

**파일 넣기**
- 화면 아무 곳에나 드래그 앤 드롭 (웹).
- 파일 고르기 버튼 (웹 · 안드로이드 공통).
- 지원 형식: `mp3` `wav` `m4a` `aac` `flac` `ogg` `opus` `mp4` `webm` `mov` `m4v` `mkv`

**단축키**

| 키 | 동작 |
| --- | --- |
| `Space` 또는 `K` | 재생 / 일시정지 |
| `←` `→` | 5초 이동 (`Shift` 함께 누르면 30초) |
| `Shift` + `←` `→` | 이전 / 다음 곡 |
| `M` | 음소거 |

## APK 받기

`main` 브랜치에 푸시하면 GitHub Actions가 자동으로 APK를 빌드합니다.

1. 저장소의 **Releases** → **Wavey 최신 빌드** 로 들어갑니다.
2. `wavey.apk` 를 폰으로 내려받습니다.
3. 설치할 때 *"출처를 알 수 없는 앱"* 허용이 필요합니다.
   (스토어를 거치지 않는 설치라서 그렇습니다.)
   삼성 폰이라면 **설정 → 보안 및 개인 정보 보호 → 보안 위험 자동 차단**을
   잠시 꺼야 할 수도 있습니다. 이건 앱이 우회할 수 없는 시스템 보호입니다.

**Actions 탭**에서 `Wavey APK 빌드` 워크플로를 손으로 실행할 수도 있습니다.

### 업데이트가 도는 원리

빌드가 끝나면 APK 옆에 `version.json` 이라는 쪽지가 같이 올라갑니다.

```json
{
  "versionCode": 42,
  "versionName": "1.0.42 (abc1234)",
  "apkUrl": "https://github.com/lyh100700/wavey/releases/download/latest/wavey.apk",
  "notes": "마지막 커밋 메시지",
  "sizeBytes": 10780333
}
```

`versionCode` 는 빌드할 때마다 1씩 오르는 번호(GitHub Actions 실행 번호)입니다.
앱은 지금 깔린 번호와 견주어 **쪽지 쪽이 더 크면** 새 버전으로 봅니다.

별도 서버가 필요 없고, 릴리스 태그가 `latest` 로 고정돼 있어 주소도 늘 같습니다.

## 직접 APK 빌드하기

Android Studio(JDK 21 포함)가 설치되어 있다면:

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleRelease
# → android/app/build/outputs/apk/release/app-release.apk
#
# 배포용은 릴리스 빌드로 만든다. 디버그 빌드는 android:debuggable이 켜져 있어
# 폰을 USB로 연결할 수 있는 사람이 앱 내부를 들여다볼 수 있다.
```
